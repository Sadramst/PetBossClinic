# Farsi and RTL Standard

The site is Farsi only (ADR-010). `i18n/routing.ts`: `locales: ['fa']`, `localePrefix: 'never'`. Middleware 301-redirects `/en/*` and `/fa/*`. The `<html>` tag is `lang="fa-IR" dir="rtl"`.

## Rules
- Use logical CSS properties (`ms-`, `me-`, `ps-`, `pe-`, `text-start`); never `left` or `right` for layout.
- All UI copy is polished Persian. Admin strings are hardcoded Persian, not in `messages/`.
- Dates are Jalali via `lib/date/jalali.ts` (`formatJalaliDate`); the admin uses `JalaliDateField`, storing ISO dates at 12:00 UTC.
- Money is Toman, formatted by `lib/format/price.ts`, with Persian digits.
- Normalise user text with `lib/text/persian.ts` (Arabic ي and ك become ی and ک) and phones with `lib/text/iran.ts` (`+98` and `09` are the same mobile).
- Search must match both Persian and Arabic letter forms and both digit sets.
