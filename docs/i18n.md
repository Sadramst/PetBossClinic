# Internationalization (i18n) & Localization Specification

This document details the bilingual architecture, routing strategy, font rendering, calendar support, and localization standards for **Pet Boss Clinic (پت‌باس)**.

---

## 1. Core Principles

1. **Farsi-First by Default**:
   - The primary audience is pet owners in Tehran, Iran.
   - The root URL `/` serves Farsi (`fa-IR`) in right-to-left (`RTL`) mode without requiring any `/fa` redirect.
2. **English as Secondary**:
   - Available under `/en` in left-to-right (`LTR`) mode.
   - Preserves path structures when switching languages (e.g., `/services` ↔ `/en/services`).
3. **Database Bilingual Model**:
   - Content models have paired fields (`nameFa` / `nameEn`, `descriptionFa` / `descriptionEn`).
   - If an English field is null or blank, the system falls back gracefully to the Persian content.

## 2. Routing & Middleware Architecture

In `middleware.ts`:
```typescript
import createMiddleware from 'next-intl/middleware';

export default createMiddleware({
  locales: ['fa', 'en'],
  defaultLocale: 'fa',
  localePrefix: 'as-needed', // Serves 'fa' at '/' and 'en' at '/en'
});

export const config = {
  matcher: ['/((?!api|_next|_vercel|.*\\..*).*)'],
};
```

In `i18n/request.ts`:
```typescript
import { getRequestConfig } from 'next-intl/server';
import { notFound } from 'next/navigation';

const locales = ['fa', 'en'];

export default getRequestConfig(async ({ requestLocale }) => {
  const locale = await requestLocale;
  if (!locale || !locales.includes(locale)) notFound();

  return {
    messages: (await import(`../messages/${locale}.json`)).default,
  };
});
```

## 3. Typography & Font Subsetting

Fonts are loaded using `next/font/google` with optimal display swapping:
- **Farsi (`locale === 'fa'`)**:
  - Font: **Vazirmatn** (variable weight 100–900).
  - Subsets: `arabic`.
  - Feature settings: `"ss01", "ss02"` for clean Persian numerals and glyph alternates.
- **English (`locale === 'en'`)**:
  - Font: **Outfit** (variable weight 100–900).
  - Subsets: `latin`.

## 4. Currency, Numerals & Dates

| Element | Farsi (`fa`) | English (`en`) |
|---|---|---|
| **Currency** | **تومان (Toman)** | **Toman** |
| **Storage** | Integer in Toman (no decimals) | Integer in Toman |
| **Digit Rendering** | Persian numerals: `۳۵۰,۰۰۰ تومان` | Western numerals: `350,000 Toman` |
| **Calendar** | **Jalali (Shamsi)** via `dayjs-jalali` | **Gregorian** via `dayjs` |
| **Phone Format** | Local: `۰۲۱-۲۲۰۰۰۰۰۰` / `۰۹۱۲۰۰۰۰۰۰۰` | International: `+98 21 22000000` |

## 5. Message Dictionaries (`messages/`)

Translations are structured into functional namespaces:
- `Navigation`: Menu links, emergency call labels, CTA buttons.
- `Home`: Hero titles, division descriptions, team headers, FAQs.
- `Services`: Pricing labels, duration badges, consultation booking.
- `About`: Clinic history, values, medical licenses.
- `Contact`: Form placeholders, map pins, working hours.
- `Admin`: Back office labels, table columns, module titles, action verbs.
- `Common`: Shared states (loading, error, save, cancel, not found).
